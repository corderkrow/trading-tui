1. Identity 2. Color 3. Typography 4. Spacing 5. Components 6. Iconography 7. Imagery 8. Animation 9. Voice 10. Do / Don't 11. Prohibited

These rules govern all AI-generated page content and designs for the coderkrow website. Follow every rule strictly. When in doubt, refer back to the source of truth: the imagotipo (mascot + wordmark lockup).

1. Identity principles

coderkrow is a tech content brand for developers; not a SaaS product, not a corporate entity. The visual language must feel crafted, opinionated, and slightly dark — like a developer who cares deeply about aesthetics.

Core traits to express in every design

  • Technical confidence — precision in spacing, grid, and typography over decorative noise
  • Edge without aggression — dark, moody palette but never heavy-metal; serious but approachable
  • Minimal chrome, maximal content — UI stays out of the way; the content is the product
  • Cyber-organic tension — the crow mascot lives at the intersection of nature and technology; that duality should echo in design choices

What to avoid at all costs

  • Generic "developer blog" aesthetics (purple gradients, neon green on black, overused grid patterns)
  • Corporate softness (rounded pastel cards, emoji-heavy headings, motivational copy)
  • Startup clichés (gradient hero text, floating 3D blobs, stock-photo developer photos)
  • Over-animation for its own sake

2. Color

Usage rules

  • Primary palette — only three colors should dominate any composition: --ck-ink, --ck-teal, and white/off-white. Everything else is supporting detail.
  • --ck-cyan is a signal color. Use it sparingly: syntax highlighting, active toggle states, a single decorative glow on the hero, code cursor blinks. Never as a background fill over large areas.
  • Never use raw #000000 or #ffffff for large surfaces — always use the ink/surface tokens; they carry the warm tint that makes the palette cohesive.

Color ratios per section

  • Background (white or --ck-surface): 70%
  • Ink / text elements: 20%
  • Teal accents: 8%
  • Cyan highlights: 2%

Permitted alpha derivations only

  • --ck-teal at 8% → subtle brand-tinted surface (#1a595a14)
  • --ck-teal at 20% → brand border (#1a595a33)
  • --ck-ink at 6% → divider / hairline (#1d1d1b0f)
  • No other ad-hoc color mixing

Rules

  • Weight is binary: 400 or 500. Never use 600, 700, or bold.
  • Headings never use all-caps except text-label. Sentence case only.
  • Line heights: display/headings 1.1; body text 1.65; code 1.6; UI labels 1.2
  • Negative tracking at display sizes is mandatory. -0.02em at 56px+ prevents the rounded letterforms from feeling spacey.
  • The wordmark split rule: "coder" is always --ck-ink and "krow" is always --ck-teal. Non-negotiable above 16px.

4. Spacing & layout

All spacing is derived from an 8px base unit. Max content width: 1200px. 12-column grid, 24px gutter. Prose caps at 680px.

  • Asymmetry over symmetry for landing sections. Deliberate visual weight shifts; not centered everything.
  • Density by hierarchy: nav/metadata dense; body content airy; hero sections sparse and typographic.
  • No full-bleed background fills on interior sections unless they carry real semantic weight.

5. Components

Buttons

Primary:   bg --ck-teal, text white, radius 6px, padding 10px 20px
           hover → bg --ck-teal-mid; no box-shadow, no gradient

Secondary: bg transparent, border 1px --ck-teal, text --ck-teal
           hover → bg --ck-teal at 8%

Ghost:     bg transparent, no border, text --ck-muted
           hover → text --ck-ink

No rounded-pill buttons (border-radius: 9999px) for primary actions. 6–8px radius only. Pills only for tag/badge elements.

Cards

  • Border: 1px solid --ck-ink at 6%. Radius: 10px. Padding: 24px.
  • Hover: border-color → --ck-teal at 20%. No lift, no box-shadow.
  • No drop shadows on cards. Planarity is the design principle; borders are the only elevation signal.

Code blocks

  • Always dark, even on light-mode pages. Background: #111110.
  • Keywords: --ck-cyan. Strings: --ck-teal-light. Comments: --ck-muted at 80%.
  • Inline code: bg --ck-teal at 8%, color --ck-teal, border-radius 3px, padding 1px 5px.

Dividers

Use space, not lines. When a divider is needed: 1px solid --ck-ink at 6%. Never a gradient divider.

6. Iconography

  • Library: Lucide or Phosphor icons, outline weight only.
  • Sizes: 16px inline, 20px actions, 24px feature icons, 32px max decorative.
  • Color: inherits text color; may use --ck-teal for branded moments.
  • The crow mascot is a brand asset, not a generic icon. Only in logo lockups, hero sections, and social profile contexts. Never below 40px or inline with body text.

7. Imagery & media

  • Flat vector style consistent with the mascot's graphic treatment. Palette must pull from brand tokens.
  • No photorealistic 3D renders or stock photo developer imagery.
  • Video thumbnails: dark background (#111110), teal or cyan for title text, authentic face shots over polished composites.
  • Embed containers use standard card treatment (10px radius, 1px border). Caption text: text-small, --ck-muted.

8. Motion & animation

Animation library: anime.js. All animation should feel intentional and developer-crafted; not bouncy, not flashy.

  • Enter animations only. Elements animate in; they do not animate out unless navigating away.
  • Duration: 200–400ms for UI; 500–800ms for page-level entrances.
  • Easing: easeOutExpo for enter. No spring physics on layout elements.
  • Stagger on lists: anime.stagger(60), max 400ms total delay.

Permitted

ElementAnimation
Hero headingtranslateY: [16, 0], opacity: [0, 1], 600ms easeOutExpo
Cards on scrolltranslateY: [24, 0], opacity: [0, 1], anime.stagger(60)
Mascot logotranslateY: [0, -6], loop + alternate, 3000ms easeInOutSine
CTA hoverCSS transform: scale(1.02), 150ms ease-out

Forbidden

  • Parallax scrolling on background layers
  • Spinning loaders (use skeleton screens or opacity pulse)
  • Slide-in drawers / panels on desktop
  • Any animation that causes layout shift
@media (prefers-reduced-motion: reduce) {
  /* All transitions collapse to opacity-only at 200ms */
  * {
    transition-duration: 200ms !important;
    animation-duration: 200ms !important;
  }
  /* Transforms disabled; only opacity changes remain */
}

9. Voice & content rules

  • Direct. Never pad. "Learn Astro in 20 minutes" beats "Discover the amazing world of Astro with this comprehensive guide."
  • Technical without being exclusive. Write for working developers.
  • First person, singular. "I build in public." Not "We create content." Personal brand.
  • coderkrow is always lowercase. Never CoderKrow or CODERKROW.
  • No em dashes, no regular dashes in copy. Short sentences; semicolons and commas for rhythm.

Heading patterns

Do
  • "Building a router from scratch"
  • "Why I rewrote it in Rust"
  • "Ship faster. Break less."
Don't
  • "Unlock the power of modern web development"
  • "Your Ultimate Guide to TypeScript"
  • "Welcome to my coding journey!"

Metadata format

  • Dates: Jun 29, 2026 — no ordinals, no spelled-out months in dense contexts
  • Read time: 8 min read — always lowercase, no period
  • View counts: 12.4K views — not 12,432
  • Tags: lowercase, no hashtag prefix — astro, typescript, web-performance

10. Do / don't reference

Do
  • --ck-teal for interactive elements
  • Headings at weight 400–500
  • --ck-cyan for code highlights and active states
  • Mascot at ≥ 40px always
  • Dark code blocks always
  • Sentence case on all headings
  • coderkrow lowercase everywhere
  • Space Grotesk as display/body font
  • JetBrains Mono for all code
  • 8px-based spacing grid
  • Border-radius 6–12px on components
  • Flat planarity-based UI (no shadows)
  • Authentic developer screenshots
  • Reduced motion compliance
Don't
  • Teal as background on large sections
  • font-weight: 700 or bold anywhere
  • Cyan as paragraph text or large fills
  • Crop, recolor, or restyle the crow mascot
  • Light-mode code blocks
  • Title Case on headings
  • CoderKrow, CODERKROW, Coderkrow
  • Inter, Roboto, Arial, or generic sans-serif
  • Courier, Monaco, or monospace fallback-only
  • Arbitrary spacing (e.g. 13px, 22px)
  • border-radius: 9999px on non-pill elements
  • Drop shadows, blur backgrounds, card lifts
  • Stock photos of keyboards or screens
  • Ignoring prefers-reduced-motion

11. Prohibited patterns

The following must never appear in any generated design or content:

  1. 01Purple or violet as any part of the palette
  2. 02Gradient text (especially multi-color gradient on headings)
  3. 03Glassmorphism / frosted blur card surfaces
  4. 04Neumorphic soft-shadow UI
  5. 05Parallax hero backgrounds
  6. 06Animated gradient mesh backgrounds
  7. 07AI-generated photorealistic imagery
  8. 08Any font other than Space Grotesk / Outfit / JetBrains Mono
  9. 09Animated emoji or Lottie decoration
  10. 10Social proof layouts with fake-looking star ratings or avatar clusters
